# Tray Icons

Place the following PNG files in this directory:

| File | Size | Usage |
|------|------|-------|
| `icon.png` | 16×16 px | Standard resolution tray icon (Windows, Linux, macOS) |
| `icon@2x.png` | 32×32 px | HiDPI / Retina tray icon (macOS, Windows HiDPI) |

## macOS
Use a **template image** (black + transparent, no colour) so the OS can
automatically invert it for dark/light menu-bar modes. The `TrayManager`
calls `setTemplateImage(true)` automatically on macOS.

## Windows / Linux
A full-colour 16×16 PNG works best. Provide a 32×32 version named
`icon@2x.png` for HiDPI displays.

> **Note:** These binary assets cannot be generated by the code agent.
> A designer or developer must supply the actual PNG files before the
> tray icon will display correctly. The app will log an error on startup
> if the icon file is missing.
